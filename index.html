Frequently Asked Questions (FAQ) & Architecture

In-depth technical architecture, Zero-Trust security mechanics, and workflow documentation.

🛡️ What is FullSafe Zero-Trust Mode & How Does It Secure Windows?

FullSafe activates a strict Default-Deny outbound policy. Traditional firewalls allow unknown background processes to silently phone home. In FullSafe mode, every outbound connection is blocked by default at the Windows Filtering Platform layer, granting internet access exclusively to executables verified in your active profiles.

⚡ How Does Recursive Directory Scanning Work?

Modern games and development IDEs distribute executables across hundreds of nested subdirectories. HaYTooL Firewall recursively traverses directory trees, discovers every standalone and sub-process binary, sanitizes paths, and synchronizes rules into Windows Firewall in a single click.

🔍 Dual-Engine Threat Intelligence: VirusTotal & MalwareBazaar

The integrated standalone Task Manager calculates SHA-256 process hashes on the fly and queries both VirusTotal v3 and MalwareBazaar intelligence databases. Suspicious network consumers can be inspected and blocked instantly without launching third-party antivirus suites.

🚀 Portable, Lightweight & Zero Telemetry Architecture

Written in native C# / WPF without bloated runtimes or persistent background daemons. Settings are stored transparently in human-readable INI format with automated 7z rotation backups. Zero background overhead, maximum privacy.
